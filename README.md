# STARMED

Frontend-сайт частной ЛОР-клиники STARMED с интерактивной демонстрационной онлайн-записью.

## Технологии

- React и JavaScript
- Tailwind CSS
- Lucide React
- Vite

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

Проект работает без backend и внешних API. Данные записи хранятся только в состоянии React и не отправляются на сервер. Иллюстрации услуг находятся в `public/visuals`.
