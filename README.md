# STARMED

React + JavaScript + Tailwind CSS + Lucide React. Только frontend, без API и серверной логики.

Запуск: npm install, затем npm run dev.
Сборка: npm run build. Готовые статические файлы находятся в dist.

Фотографии взяты из Photo for web-site; обрезанные копии лежат в public/images. Исходники сохранены.
Цены, профили специалистов, график и отзывы демонстрационные. Контактные данные не выдуманы: кнопки показывают уведомление до заполнения реальных данных.
Запись работает в useState и не сохраняется после перезагрузки. Реальные приёмы не создаются.
